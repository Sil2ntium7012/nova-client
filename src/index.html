Nova Client 이용 안내

Nova Client는 마인크래프트용 비공식 서드파티 런처입니다. Mojang, Microsoft 와 직접적인 제휴 관계가 없으며, 마인크래프트 정식 실행을 돕기 위한 도구입니다.

  • 로그인 시 사용하는 Microsoft 계정 인증 정보는 이 기기에만 저장되며, 외부 서버로 전송되지 않습니다.
  • 런처는 마인크래프트 실행에 필요한 자바, 게임 파일, 모드, 리소스팩을 사용자의 PC에 다운로드합니다.
  • 제공되는 모드/리소스팩은 각 원저작자의 라이선스를 따르며, 이 클라이언트는 배포 편의를 위한 묶음일 뿐입니다.
  • 클라이언트 이용 중 발생하는 문제에 대해 제작자는 책임을 지지 않으며, 문제 발생 시 디스코드로 문의해주세요.
  • Nova 사이트 계정(이메일/아이디와 비밀번호로 만드는 계정)은 Microsoft 계정과는 별개로, Nova Client와 Nova 사이트(웹)에서 함께 사용하는 자체 계정입니다. 계정 인증과 코인/구매 내역 관리를 위해 자체 서버에 안전하게 저장됩니다.
