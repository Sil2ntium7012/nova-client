Nova Client 고정 부트스트랩
===========================

NovaClient-Setup.exe (이 폴더의 것)  =  사이트/디스코드에 올려 유저에게 배포하는 파일
NovaClient-Setup.exe (GitHub 릴리스) =  진짜 설치 파일 (electron-builder 가 만드는 것)

★ 절대 다시 컴파일하지 마세요 ★
-----------------------------------
Windows SmartScreen 평판은 "파일 해시" 단위로 쌓입니다. 이 exe를 다시 만들면
해시가 바뀌면서 지금까지 쌓인 평판이 전부 사라집니다.

이 안에는 버전 정보가 하나도 들어있지 않고, 다운로드 주소도 "latest" 뿐이라
런처를 아무리 새로 배포해도 이 파일은 손댈 필요가 없습니다. 그게 이 파일이
존재하는 이유입니다.

하는 일 (24-125차부터: Nova 디자인 창 하나로 끝까지)
-------
1) latest.yml 을 받아 설치 파일 크기를 알아냄 (진행률 계산용)
2) curl.exe 를 창 없이 띄워 설치 파일을 받고, 받는 동안 진행률 바를 채움
   (curl 이 없거나 실패하면 urlmon 으로 통째로 받음 - 진행률 없이)
3) 받은 설치 파일을 /S 로 조용히 실행 -> 설치 창이 화면에 안 뜸
   (조용한 설치가 실패하면 설치 파일을 그냥 띄워서 직접 진행할 수 있게 함)
4) "설치가 끝났어요" 를 잠깐 보여주고 종료. 임시 파일은 NSIS 가 정리

즉 처음부터 끝까지 Nova 창 하나만 뜨고, 윈도우스러운 설치 마법사는 안 보입니다.

창 모양 (24-126차)
-----------------
960x600, 테두리와 윈도우 제목표시줄 없음(화면 가운데 고정). 배경은 우주 이미지
(bg.bmp - makebg.py 가 생성: 성운, 별, 행성 림라이트, NOVA CLIENT 워드마크).
가운데에 상태 문구, 아래쪽에 가로 800px 보라색 게이지와 진행률(%, MB) 표기,
오른쪽 위에 직접 그린 X. 게이지는 uxtheme 를 꺼서 Nova 보라색으로 칠함.

프로그램이 받은 파일에는 인터넷 표식(MOTW)이 붙지 않아서, 다운로드된 진짜
설치 파일을 실행할 때는 SmartScreen 경고가 뜨지 않습니다. 즉 브라우저로 직접
받는 파일은 이 부트스트랩 하나뿐이고, 평판도 이 하나에만 쌓입니다.

다시 만들어야만 하는 경우
------------------------
- GitHub 저장소 주소(owner/repo)가 바뀔 때
- 릴리스 에셋 이름(NovaClient-Setup.exe)이 바뀔 때
이때만 bootstrap.nsi 의 SETUP_URL 을 고치고 다시 컴파일합니다.
(빌드: python3 makebg.py 로 bg.bmp 를 만든 뒤 makensis bootstrap.nsi
      (icon.ico, bg.bmp 가 같은 폴더에 있어야 함))

주의
----
릴리스에 NovaClient-Setup.exe 가 없으면 이 부트스트랩이 동작하지 않습니다.
빌드해서 릴리스 올릴 때 파일 이름을 바꾸지 마세요.
